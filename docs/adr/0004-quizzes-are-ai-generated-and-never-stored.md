# Quizzes are AI-generated and never stored

Every quiz is generated by an AI provider, with items from the dataset as context, and returned without being stored; each request produces a new quiz. The dataset-only quiz mode of the earlier jlpt-foundation project was dropped: it could only ask meaning questions, and a second generation path doubled the quiz logic for the weaker result. Storing quizzes was rejected because nothing reads a past quiz until answers and progress exist.

## Consequences

A quiz request fails when no AI provider is configured. Local development uses the `mock` provider.
